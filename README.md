## 📚 課程系統(國中 → 博士,每級 21 課 × 五單元,共 105 課)

每個等級卡片上的「📚 課程 n/21」進入課程列表;每課含五個單元,五單元全完成即「修畢」該課,進度逐課記錄:

| 單元 | 內容 |
|---|---|
| 📖 課文 | 每課一篇原創課文(主題不重複)+ 朗讀/慢速音檔 + 中文翻譯切換。**朗讀時逐字卡拉OK高亮**(Edge TTS WordBoundary 時間戳);**課文任何單字皆可點擊**,彈窗顯示發音、英英釋義、中文說明與課文例句。**朗讀中點字會自動暫停課文**(高亮停在原處),關閉彈窗後從暫停處無縫續播(單字發音使用獨立播放器,不干擾課文進度)|
| 📝 字詞 | 課文核心 8 字(附發音,與冒險字庫連動)|
| 🔊 發音 | 每課一個不重複的發音重點 + 3 題聽辨(含音檔)|
| 🎧 聽力 | 重聽課文(不看字)後答 3 題理解選擇題 |
| ✍️ 文法 | 每課一個不重複的文法/學術修辭點:講解 + 例句 + 4 題測驗附解析 |

**課程主題走向**:國中(生活敘事:運動會、夜市、颱風天、露營…)→ 高中(成長議題:志工、留學、社群壓力、Gap Year…)→ 大學(社會議論:遠距工作、假新聞、零工經濟、高齡化…)→ 碩士(研究方法:文獻回顧、統計顯著性、同儕審查、論文寫作…)→ 博士(學術修辭與批判:典範轉移、引用政治、Hedging/Boosting、學術勞動…)。

**文法梯度**:國中 20 個基礎文法(時態、比較級、介係詞、附加問句…)→ 高中 20 個進階句型(假設語氣三類、倒裝、間接引述…)→ 大學 20 個學術句型(分裂句、獨立分詞構句、非人稱被動…)→ 碩士 20 個學術寫作術(立場動詞、引用句型、趨勢描述、範圍限定…)→ 博士 20 個學術修辭(讓步反駁、文獻缺口、情態階梯、限制句型…)。

**發音梯度**:國中 phonics 基礎(th、l/r、魔法 e、-ed 三讀…)→ 高中子音母音對比與重音規則 → 大學學術字重音規律(-ic、-ity、-ate…)→ 碩士學術詞彙精準發音(albeit、paradigm…)→ 博士長字重音與外來語(epistemology、zeitgeist /ts/…)。

## 遊戲模式(每個難度等級皆有)

### ⚔️ 冒險模式(輸入)
每關 10 場戰鬥:單字戰與**語塊戰**交錯,最後打 Boss(連續 3 題 + 終極拼字)。
- 單字題型:🎧 聽音辨義、📖 英翻中、✍️ 中翻英
- 語塊題型:🧩 **語塊填空**(`___ a consensus` 選正確搭配動詞)、📖 **英英釋義**(讀英文釋義選語塊)
- 答題後自動播放發音、語塊題附英英釋義;答錯扣 HP 並進入結算「錯題複習」(可重聽)

### 🎤 跟讀特訓(Shadowing)
每次 8 句真實例句:先聽**原速 / 🐢 慢速**原音 → 🎙️ 用麥克風錄下自己的跟讀 → 👂 播放比對語調與連音,訓練口腔肌肉記憶。

### ✍️ 輸出挑戰(Output)
先**聽**例句(不看字),再用目標語塊**造出自己的句子**(至少 6 個字、動詞可變時態、不能照抄)。系統檢查語塊是否真的用出來,並揭示範例原句對照。

### 🤖 AI 對話教室(即時分析文法・發音・切題度)

與 **KIMI(Moonshot AI)** 進行真實英語對話(五個等級各有對應 CEFR 難度與話題)。AI 主動發起話題、一次問一個問題,並在**每一輪**你回覆後給出回饋卡:

- 🖊 **文法**:錯誤片段 → 修正 + 中文解釋
- 🎯 **內容**:是否切題回應了 AI 的問題
- 🎤 **發音**:用 🎙️ 語音輸入時,辨識偏差的字視為可能的發音問題,AI 推測你想說的字並給 KK 音標/嘴型建議(例:「聽起來像 sink,你想說的是 think /θɪŋk/,舌尖放齒間…」)
- 💛 鼓勵與本輪 0–100 評分;AI 回覆可自動朗讀(瀏覽器 TTS)

語音輸入使用瀏覽器 Web Speech API(Chrome/Edge 支援)。

### 📺 看影片學英文 AI 口說(參考 VoiceTube)

探索分頁內建 **22 支**經典英語演講與科普影片(YouTube 內嵌,每支都已驗證存在、可內嵌、有英文字幕),依 CEFR 分級:**A2 3 支**(Kid President、TED-Ed 30 天挑戰、Kurzgesagt)、**B1 4 支**(Emma Watson、McRaven、Angela Duckworth、Jim Carrey)、**B2 6 支**(Steve Jobs、Simon Sinek、Julian Treasure、哈佛幸福研究、Shawn Achor、Josh Kaufman)、**C1 5 支**(Amy Cuddy、Tim Urban、Kelly McGonigal、Dan Pink、Guy Winch)、**C2 4 支**(Ken Robinson、Brené Brown、Johann Hari ×2),主題涵蓋勵志/職場/心理/教育/社會/學習/故事。

每支影片有 4~6 句口說練習句(共 109 句)。**新影片的練習句由 `build_video_sentences.py` 從該片真實字幕中擷取**(挑選長度適中、平均分散全片的句子),再由 KIMI 自動翻成繁中——句子是影片真的說過的話,並附**時間戳**,卡片上的「▶ 影片 0:16」可直接跳到影片該處對照。每句提供:

1. **看影片**抓語感 → 每句可播 **Edge TTS 原速/慢速**示範
2. **🎙️ 口說挑戰**:開口唸句子,語音辨識後**逐字比對評分**(綠色=唸對、紅色波浪線=漏掉/唸錯),80 分達標、逐句記錄最佳分數
3. **🤖 AI 講評**:把目標句與辨識結果交給 KIMI,取得 KK 音標級的發音矯正建議(如「foolish 被聽成 furious:/ˈfulɪʃ/ 沒有 r 音,舌尖別捲」)
4. 句中**任何單字可點**,共用單字彈窗(發音+離線英英+中文)

**📜 同步文字稿**:用 `fetch_transcripts.py`(yt-dlp)抓取每支影片的英文字幕時間軸(優先人工字幕、次選自動字幕),存於 `js/transcripts.js`。影片頁顯示完整文字稿:播放時**目前句子自動亮起並跟隨捲動**(YouTube IFrame API 對時)、**點時間戳跳轉到該句**、句中每個單字可點查(離線詞典已擴充涵蓋字幕用字,98%;人名等走線上翻譯)。

**✍️ 文法詞態解析**:每行字幕的 ✍️ 按鈕展開兩層分析——
1. **詞態變化(離線即時)**:自動偵測句中每個變化詞並還原原形(dropped→drop 重複字尾、better→good 不規則、classes→class 複數…),不規則動詞表 + 規則字尾判斷
2. **🤖 AI 文法解析(KIMI)**:時態與句型結構、逐字詞態說明、值得記的片語搭配;結果快取於本機,同一句只花一次 API

**🔁 單句循環**:任一字幕行按 🔁 即進入單句循環,播到句尾自動跳回句首反覆播放,上方顯示循環中的句子與「停止循環」;精聽同一句時不用手動倒帶。

**🎙️ 任一句都能挑戰**:口說挑戰不再限於精選名句——字幕的每一行都有 🎙️,按下即錄音、逐字比對評分並可要 AI 講評。

**🏷 CEFR 分級與主題篩選**:影片卡片標示 A2~C2 難度、主題標籤(勵志/職場/TED/心理/教育…)與「✔ 字幕」標記,上方可依難度與主題交叉篩選。

新增影片流程:在 `js/videos.js` 加一筆(yt ID + cefr + tags,`sentences: []` 留空),依序執行 `fetch_transcripts.py`(抓字幕)→ `build_video_sentences.py`(擷取練習句 + 翻譯)→ `generate_audio.py`(TTS)→ `build_dictionary.py`(詞典)。

> 影片皆以 YouTube 官方播放器內嵌播放(附作者與原片連結),字幕與擷取的練習句僅存於本機供個人學習對照使用。

|---|---|
| /ɪ/ vs /i/ | ship 🆚 sheep |
| /ɛ/ vs /æ/ | bed 🆚 bad |
| /ʌ/ vs /ɑ/ | cup 🆚 cop |
| /ʊ/ vs /u/ | full 🆚 fool |
| /oʊ/ vs /ɔ/ | coat 🆚 caught |
| /ɝ/ 捲舌 | work 🆚 walk |

玩法:每輪 10 題**最小對比詞聽辨**(播 ship,選 ship 還是 sheep),答錯會多留時間讓你「成對比對」兩個字的發音,抓住長短與鬆緊的差別。各道場最佳正確率會記錄在地圖上。

### 🌊 商務連音特訓(真實語速聽力)
母語人士在會議中靠**連音(Linking)、閃音(Flap T)、弱讀(Reduction)**維持節奏。18 句商務會議例句(自然語速 + 慢速兩種預錄音檔):

1. **聽寫**:聽自然語速,把被縮減的部分打出來(`Let's ____ ____ ____ before the deadline.`),口語縮寫 gonna / wanna / shoulda / a lotta 也算對
2. **機制揭示**:答完顯示發生了哪種機制、實際聽起來的樣子(`get it done → ge‿di‿dun`)與說明
3. **跟讀**:再用自然語速跟讀 3 次,讓嘴巴記住節奏

最佳聽寫正確率記錄在主畫面。
